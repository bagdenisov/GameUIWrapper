# GameUI Wrapper / hooked и так далее
If you a englishman you can translate this text in translator. I don't want write a useless text in another langluage. Sorry :p

Моя отчаянная попытка понять как работают интерфейсы на движке GoldSource и написать для него обертку, дабы вызовы можно было перенаправлять. По итогу смог разобраться, но столкнулся с тем, что видимо при инициализации или запуске интерфейса он передает ему адреса памяти, которые hw.dll обращает к обертке, из-за чего возникают нарушения доступа к памяти. Это уже за грани моего познания. Может кто-то сможет реализовать задумку.

За основу брался проект реверс инжиниринга [GameEngine-reGoldSrc](https://github.com/gmh5225/GameEngine-reGoldSrc). Он как раз базируется на стимовской версии халфы, что и позволило начать узнавать как работают интерфейсы.
